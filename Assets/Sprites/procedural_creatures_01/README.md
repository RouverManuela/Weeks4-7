# Procedural Creatures 01

~800 sprites included in this pack of procedurally generated creatures, usable in any game engine that supports spritesheets. 

If you would like to see more creature packs, my itch.io page can be found [here](https://bec0.itch.io/)

Thanks for downloading this pack! Feel free to [contact](mailto:bartholameu0@gmail.com) me for any requests/questions as well.

---

## Contents

- **Creatures:** 10
- **Scales:** 1x, 2x, 4x, 8x
- **Outline variants:** outline, no-outline
- **Animations:** idle (bob, float, sway, wiggle, breathe); celebrate (jump, bounce, shake); flash (bright, dark)
- **Params JSON:** included per creature
